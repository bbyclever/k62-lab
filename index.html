Sin escrituras

Ya confirmamos la conexión GATT y las lecturas. El SDK oficial de iOS documenta una secuencia de conexión, vinculación, inicialización y consulta de capacidades (allConfig()), pero no publica aquí los bytes necesarios para ejecutarla directamente desde Bluefy.

Para ejecutar FitCloudKit hace falta una aplicación nativa compilada para iOS. Esta web no incorpora ese SDK y todavía no puede reorganizar aplicaciones ni responder mensajes desde el reloj.
